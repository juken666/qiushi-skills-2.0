## 安装

### 方式一：一键安装（推荐）

```bash
# 使用 skills.sh 安装器
npx skills add juken666/qiushi-skills-2.0
```

### 方式二：手动安装

1. 找到你的 AI 工具的 skills 目录：
   - Claude Code: `~/.claude/skills/`
   - Cursor: `~/.cursor/skills/`
   - 其他工具: 查看对应文档

2. 复制本仓库的 `skills/` 目录下的所有文件夹到上述路径

3. 重启你的 AI 工具，即可使用

## 使用示例

```
用户      🗣️ 我要创业做自媒体，但不知道怎么开始，很迷茫。
教员      🎙️ 从实际出发，先调查研究。
            不要一上来就全职，先利用业余时间验证。
            矛盾分析：你的主要矛盾是什么？是内容能力？还是流量获取？
            先解决主要矛盾，其他问题会迎刃而解。
            没有调查就没有发言权，先去了解这个行业的真实情况。

用户      🗣️ 网上有人骂我，很难受。
教员      🎙️ 矛盾分析法：分析骂你的人是谁，他们的立场是什么。
            批评与自我批评：有则改之，无则加勉。
            战略思维：不要四面出击，要分清主次。
            持久战略：不要因为暂时的困难就放弃。
```

## 核心原则

### 实事求是
**核心要义**：从客观存在着的事物出发，让事实规定判断，让现实修正理论。

**原著出处**：《改造我们的学习》

**核心要求**：
- 不凭主观想象
- 不凭一时热情
- 不凭死的书本
- 凭客观存在的事实

---

## 九大思想武器

1. **矛盾分析法** - 分析各群体的经济地位和政治态度，分清敌友
2. **实践认识论** - 实践、认识、再实践、再认识
3. **调查研究** - 没有调查就没有发言权
4. **群众路线** - 从群众中来，到群众中去
5. **批评与自我批评** - 有则改之，无则加勉
6. **持久战略** - 战略上藐视敌人，战术上重视敌人
7. **集中兵力** - 抓住主要矛盾，集中优势兵力
8. **星火燎原** - 星星之火，可以燎原
9. **统筹兼顾** - 弹钢琴工作法，统筹全局

## 诚实边界

**这个 Skill 能做的**：
- 用教员的方法论框架分析现实问题
- 提供系统性的思维工具
- 帮助用户建立正确的认识论和方法论

**这个 Skill 做不到的**：
1. **替代专业咨询**：投资、法律、医疗等专业领域
2. **预测未来**：基于当前信息分析，但不能预测未来
3. **解决所有问题**：方法论是工具，具体执行靠个人
