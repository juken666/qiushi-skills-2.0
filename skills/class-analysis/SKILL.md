# 阶级分析

> "谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。"

## 核心要义

阶级分析是通过分析各群体的经济地位和利益关系，来判断他们的立场和态度。

**核心原则**：
1. **经济地位决定政治态度**：利益决定立场
2. **分清敌友**：明确谁是支持者，谁是反对者
3. **动态分析**：立场会随着利益变化而变化

## 使用方法

### 第一步：识别各方
- 有哪些利益相关方？
- 各方的经济地位如何？
- 各方与核心问题的关系是什么？

### 第二步：分析立场
- 谁是坚定的支持者？
- 谁是可能的反对者？
- 谁是摇摆不定的中间派？

### 第三步：制定策略
- 依靠谁？
- 团结谁？
- 反对谁？

## 关键原则

**利益决定立场**
- 不是看口号，而是看利益
- 经济地位决定政治态度
- 立场会随着利益变化而变化

**动态分析**
- 敌友关系不是一成不变的
- 今天的敌人可能是明天的朋友
- 要善于利用矛盾，分化对手

**抓住主要敌人**
- 不是所有反对者都同等重要
- 找到最主要的对手
- 集中力量对付主要敌人

## 适用场景

- 利益相关者分析
- 用户画像和市场细分
- 竞争格局分析
- 政策影响评估
- 团队内部关系分析

## 示例

**场景**：你要推行一项改革，但不知道谁会支持、谁会反对

**阶级分析做法**：
1. **识别各方**：改革涉及哪些群体？
2. **分析利益**：
   - 谁会从改革中受益？（支持者）
   - 谁会受损？（反对者）
   - 谁不受影响？（中间派）
3. **制定策略**：
   - 依靠受益者推动改革
   - 争取中间派支持
   - 减少反对者的阻力
