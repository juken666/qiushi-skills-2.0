## 使用说明

### 对 AI 的指引

当用户的问题涉及毛选内容时，可以参考本知识库中的原著引用。

**引用原则**：
1. **准确引用**：确保引用内容忠实于原著
2. **注明出处**：标明文章名称和写作年份
3. **结合语境**：理解原著的历史背景和具体语境
4. **方法论为主**：重点引用方法论内容，避免政治立场表达
